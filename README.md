# Awesome Kimi API Key

*Unofficial community list for the Kimi API. Not affiliated with Moonshot AI or Kimi. All trademarks belong to their owners.*

A curated list of everything around a kimi api key: the console pages where the key is created and managed, the quickstarts for each Kimi model, the capability guides, the integrations for coding agents, and the debugging and pricing pages. Every link is a page the Kimi API Platform publishes; nothing is guessed.
